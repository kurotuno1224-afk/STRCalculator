# Delivery Rules

## Implementation Order

Phase 1: initialize project structure and basic layout
Phase 2: unified data layer
Phase 3: character list page
Phase 4: character detail page
Phase 5: flat UI refinement
Phase 6: cleanup and README

## Output Protocol

For each response:

1. show the project tree if structure changes
2. list the files you are creating or modifying
3. provide full code with file paths
4. do not skip required files
5. do not output pseudocode
6. do not implement future phases early
7. stop after the current phase

## README

The final README must include:

- overview
- stack
- structure
- data layer design
- adapter strategy
- backend replacement path
- run instructions
- future extensions
