# UI Rules

Use a flat UI style.

## Visual Direction

- no heavy shadows
- no glow
- one primary color plus grayscale
- lightweight cards with 1px borders
- small border radius
- information first
- weak decoration

## Typography

- clear H1 / H2 / Body / Caption hierarchy
- avoid oversized decorative headings
- prioritize readability and scan efficiency

## Product Feel

The site should feel like:

- a game wiki
- a structured data tool
- not a flashy marketing page
